Приветствую! Чтобы протестировать AuthServer, нужно запустить все сервисы
(AuthServer, Client, DiscoveryServer, GatewayServer, ResourceServer).
Дожидаемся регистрации всех сервисов в Eureka Server.
Далее переходим на адрес localhost:8080/auth-server/registration.
Регистрируемся и тестируем систему!
